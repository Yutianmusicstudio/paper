## 选刊决策流程
1. 看稿件主体是"干预效果"还是"技术接受/设计" → 前者投治疗/教育类，后者投数字健康/HCI 类。
2. 时间紧 → 优先 Frontiers、JMIR 系列、MDPI；时间充裕 → 优先学科会刊。
3. 每篇稿件准备 **第一志愿 + 两个备选**，拒稿后 48 小时内转投。
