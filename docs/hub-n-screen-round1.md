# Hub N 主 / Hub D 副：第一轮粗筛（2026-11-03）

筛选标准，按顺序一票否决：数据可得且许可清楚 → 技术门槛当前可跨 → 查重仍 🟢 或可差异化 → 与核心共享资产 → 可发概率。

## 一、数据集核实结果（本轮新发现，已修正规划）

| 数据集 | 许可 | 获取 | 本轮发现 | 对 idea 的影响 |
|---|---|---|---|---|
| OpenMIIR | PDDL 公有领域，确认 | GitHub 给 HTTP 与 Academic Torrents 两条路；raw FIF 每被试约 670–750 MB，有效被试 9–10 人 | 刺激为商业录音片段，仓库提供元数据，音频需自备 | N-S3 可开；N-S1 可开 |
| Di Liberto 2020（Dryad） | Dryad 政策全站 CC0 | 直接下载；含 EEG、刺激音频与原始 MIDI | 有 MIDI 意味着符号惊异度（IDyOM、Music Transformer）可直接算；有音频意味着 MERT / MusicGen 嵌入可直接算 | N-S4、N-S9 的首选数据，**零摩擦** |
| MET（Cheang 2026） | **未能核实**；DataPort 版与 OpenNeuro 版是两个发行版（CSV 8 导 vs BIDS 全通道） | OpenNeuro ds008701 | **每次听乐 130 秒，听前 / 听后各只有 5 秒**，不足以做"状态转换"分析 | N-S5 原设计不成立，需重设计；N-CORE-2 仍可用其音乐段与 SAM 评分 |
| OSF 3u2gt | **未能核实** | — | 很可能对应 2023 PLOS ONE 悲伤自传回忆 + 悲伤拉格研究（IIT Mandi，20 人，非音乐家），但 OSF 页未确认 | N-S6 降为待核实 |
| NMED-T | CC BY 3.0（仓库页）| Stanford Digital Repository，39 GB，清洗后 MATLAB 格式 | **刺激音频不随数据发布**，只给元数据链接，需自行获得商业音轨 | 编码模型类研究有摩擦，排在 Di Liberto 之后 |
| MUSIN-G（ds003774） | CC0 | OpenNeuro | 参与者均为非音乐家 | 只作复制数据源 |
| ds002725 EEG-fMRI | CC0 | OpenNeuro / NEMAR | 21 人，情感音乐 | N-CORE-2 数据源 |

近邻更新：CNS 2026 年 3 月有一张海报比较 MusicGen 隐状态与 EEG（两个实验室内部数据集，n=26、38，仅摘要）。N-S9 从 🟢 调为 🟡，公开数据 + 专业度调节 + MERT 对比仍是差异点，但要快。
