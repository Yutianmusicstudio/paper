## 评分规则
- 判定：🟢 两轮检索无同类型论文；🟡 有近邻但类型/对象/角度不同或仅摘要/预印本/学位论文/方案；🔴 近 2 年同行评审期刊已有同类型+同对象+同技术
- 可发概率（判断估计）：起点 60；🟢 +15，🟡 +0，🔴 直接丢弃；不需伦理 +5；文体成熟（综述/审计/信息质量/基准）+5；需招募 −10；需临床机构 −15；与 hub 核心共享文献或数据 +5；上限 85
- 保留条件：判定非 🔴 且 概率 ≥ min_probability_keep 且 周期 ≤ max_months

## 禁止
- 编造近邻论文；每个近邻必须附链接
- 把同一数据切成多篇（salami）
- 在循环中途停下来问人
