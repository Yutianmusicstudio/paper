# 标准流程：从选题到投稿（目标 ≤ 16 周）

| 周 | 阶段 | 产出 |
|---|---|---|
| 1 | 选题 + 选刊 | `outline.md`：研究问题、设计、目标期刊 ×3、字数上限 |
| 2–3 | 文献检索 | 检索式、PRISMA 流程图、纳入文献表 `refs.bib` |
| 4–8 | 数据 / 分析 | 综述：数据提取表；问卷：伦理 + 发放；计量：导出 + 清洗 |
| 9–11 | 初稿 | `manuscript.md` 完整 IMRaD，图表入 `figs/` |
| 12 | 内审 | 用 `templates/checklist.md` 逐条自查；语言润色 |
| 13 | 投稿 | `cover-letter.md`；记录到 `submission-log.md` |
| 14–16 | 等待 / 并行下一篇 | 开启下一个 A 级选题 |

## 拒稿处理
- 收到意见当天归档到 `submission-log.md`。
- 可改的意见 1 周内改完，转投备选期刊，不空等。

## 写作原则（面向 Q2–Q3 期刊审稿人）
- 摘要前两句必须说清"缺口"与"本文做了什么"。
- 引言结尾明确列出 RQ1–RQ3。
- 方法可复现：检索日期、数据库、软件版本、统计方法全写。
- 讨论分三段：主要发现与文献对照、实践意义、局限与未来方向。
- 结论不超过 150 词。
