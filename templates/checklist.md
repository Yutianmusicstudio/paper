# 投稿前自查清单

## 内容
- [ ] 摘要前两句说清缺口与贡献
- [ ] 引言结尾列出 RQ
- [ ] 方法满足对应报告规范（PRISMA / STROBE / CONSORT / COREQ）并附清单
- [ ] 所有参考文献有 DOI，`[VERIFY]` 标记已全部清除
- [ ] 讨论包含局限与未来方向
- [ ] 结论 ≤ 150 词

## 格式
- [ ] 符合目标期刊字数、引用格式、图表数量限制
- [ ] 图表有编号、标题、来源，分辨率 ≥ 300 dpi
- [ ] 关键词 5 个，不与标题重复
- [ ] 作者贡献（CRediT）、利益冲突、数据可用性声明齐全

## 行政
- [ ] 伦理批号 / 豁免说明
- [ ] 预注册链接
- [ ] 投稿信完成
- [ ] `submission-log.md` 已记录投稿日期与期刊
